# Vision & Diagram Intelligence

## Supported Diagram Types

1. **Architecture Diagrams**: Detects services, APIs, databases, queues, and connection protocols.
2. **ER Diagrams**: Extracts tables, columns, primary keys, and foreign key relations.
3. **UML Diagrams**: Extracts classes, methods, and inheritance hierarchies.
4. **UI Screenshots**: Extracts visible UI elements (`LoginForm`, buttons, inputs).
